## Compatibility Notes

DataTable Pro Editor v1.1.0 is packaged for Unreal Engine 5.8. Older UE 5.7-compatible releases do not include the new v1.1.0 workflows documented here.

The plugin is editor-only. It does not add a runtime gameplay dependency, does not require Blueprint modification, and has no external third-party dependencies.
